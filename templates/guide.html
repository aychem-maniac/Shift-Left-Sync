URL 입력부터 리포트 확인까지
간단한 흐름으로 진행됩니다

사용자는 검사 대상 URL과 스캔 강도를 선택하고,
시스템은 백그라운드에서 스캔을 실행한 뒤 결과 리포트를 제공합니다.

1

로그인 또는 회원가입

사용자별 스캔 기록과 리포트를 저장하기 위해 계정으로 로그인합니다. 신규 사용자는 회원가입 후 관리자 승인을 받습니다.

2

검사 대상 URL 입력

허가받은 웹 서비스의 URL을 입력합니다. 실제 서비스에 무단으로 스캔을 수행하면 문제가 될 수 있으므로 승인된 대상만 입력해야 합니다.

3

스캔 강도 선택

low, medium, high 중 원하는 탐지 강도를 선택합니다. 강도가 높을수록 더 많은 검사를 수행하지만 시간이 오래 걸릴 수 있습니다.

4

스캔 실행

서버는 Nmap, ZAP, SQLMap, Header Scanner 등을 순차적으로 실행하고 결과를 하나의 형식으로 정규화합니다.

5

결과 리포트 확인

스캔이 완료되면 HTML, CSV, JSON 리포트를 확인하고 다운로드할 수 있습니다.
